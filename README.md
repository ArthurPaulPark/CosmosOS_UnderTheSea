2026 해양과학 AIx빅데이터 경진대회(데이터분석 대학부) 출품작.
세 개의 독립 과제를 하나의 구조로 푼다.

| 문제 | 과제 | 형태 | 데이터 규모 |
|---|---|---|---|
| **P1** | 수온 자동 품질관리 | 이진 분류 (이상 탐지) | train 776,706행 / test 169,011행 |
| **P2** | 중간층 수온 연직 복원 | 회귀 (결측 복원) | observations 789,408행 |
| **P3** | 유의파고 단기 예측 | 회귀 (6개 리드타임) | wave 118,152행 + atmos 130,896행 |

## 2. 핵심 설계

### 2.1 잔차만 학습한다

세 문제 모두 물리·통계적 베이스라인을 먼저 세우고 **그 잔차만** 모델에 맡긴다.

```
P1   자기 시계열 기준선 (7일 인과 중앙값)   →  편차를 분류
P2   깊이 선형보간 (층 1 ↔ 층 5)          →  잔차를 회귀
P3   지속성 (기준 시각 파고 유지)          →  잔차를 회귀
```

베이스라인이 설명하는 부분을 모델이 다시 배우지 않으므로 적은 데이터로도 안정적이고,
모델이 실패해도 베이스라인 수준으로 열화할 뿐 붕괴하지 않는다.

### 2.2 학습 조건을 채점 조건에 맞춘다

학습 구간과 채점 구간의 **변수별 가용률을 전수 대조**하고, 불일치가 나오면 학습 쪽을
채점 쪽에 맞춘다.

| 문제 | 발견한 불일치 | 조치 | 효과 |
|---|---|---|---|
| P2 | 하부 경계(층 5) 존재율 학습 99.2% vs 채점 **70%** | 학습·검증 양쪽에서 같은 비율로 경계 은폐 | RMSE 1.104 → 0.785 |
| P2 | 심층(6·7·8) 존재율 학습 40~81% vs 채점 **99%** | 심층 관측이 있는 학습 행에 가중치 4 | 4창 평균 1.043 → 0.928 |
| P3 | 기상 관측 보유율 학습 54.7% vs 채점 **97.5%** | 기상 없는 학습 케이스 가중치 0.25 | 롤링 0.757 → 0.749 |

P2는 이 보정을 **검증에도** 적용하기 전 RMSE가 0.4533이었다. 그러나 그것은 모델이 실제로는
만나지 않는 조건에서 잰 값이다. 같은 은폐를 검증에 적용한 **0.6079**를 공식 지표로 기록한다.

### 2.3 임계값은 분할이 아니라 문제 정의에 고정한다

P1의 결정 임계값을 검증 분할의 F1 최대점으로 잡으면 그 분할의 잡음에 적합된다. 대신
**관측된 이상 발생률과 같은 비율**(3.62%)의 행을 양성으로 낸다.

이 선택은 리더보드로 검증됐다. 출력률을 5.0%로 올린 제출은 F1이 **0.7216 → 0.6442로
떨어졌다.** 두 관측치로 역산하면 현재 컷 바로 아래 구간의 한계 정밀도는 8~14%이고, F1이
개선되려면 손익분기 약 36%를 넘어야 한다.

## 3. 문제별 접근

### P1 — 수온 자동 품질관리

주입된 이상 5종을 탐지한다. 이상 행은 32,126개지만 **연속 이벤트로는 272개**뿐이고,
유형별 성능 구조가 여기서 결정된다.

| 유형 | 이벤트 수 | 같은 기간 재현율 | 연도 이월 fold 재현율 |
|---|---:|---:|---:|
| flatline | 53 | 0.982 | 0.989 |
| noise | 52 | 0.848 | 0.921 |
| **drift** | **32** | 0.628 | **0.302** |
| **offset** | **33** | 0.789 | **0.458** |

오른쪽 열은 학습 데이터를 연도로 갈라 만든 fold에서 잰 값이다. `test.csv`에는 라벨이 없어
채점 구간의 유형별 재현율은 우리가 알 수 없다.

**핵심 피처 3종**

- **층간 편차** — 같은 시각 다른 층의 중앙값 대비 편차. 이웃 층이 함께 움직이지 않으면
  계기 문제다. 이 축에도 `temp`와 동일한 롤링·추세·런길이 통계를 전부 적용한다.
- **7일 장기 기준선 잔차** — 주입된 offset은 최대 86.5시간 지속된다. 48시간 창에는 offset이
  통째로 들어가 기준선이 이상값과 함께 이동한다. 7일 창에서는 대비가 확보된다.
- **런길이·고유값 개수** — flatline 판별의 핵심. 정상 구간의 최대 연속 동일값은 4다.

**모델** — `standard`(238 피처)와 `full`(298 피처) 두 프리셋의 LightGBM 확률을 **균등 평균**한
뒤 임계값을 적용한다. 두 프리셋은 유형별 강점이 갈린다(`full`은 offset, `standard`는 drift).
**둘 다 있어야 제출 답안이 재현된다.**

### P2 — 중간층 연직 복원

층 2·3·4의 수온을 상하 관측층에서 복원한다. 오차는 **층 4에 집중**된다
(층 2 = 0.181 / 층 3 = 0.404 / **층 4 = 0.957** ℃).

층 4(14.87 m)는 수온약층의 급경사 위에 놓여 있어, 그날 수온약층 위치에 따라 곡률이 달라진다.

- **베이스라인** — 표층(4.18 m)과 하부 경계(19.15 m) 사이 깊이 선형보간.
- **경계 복원** — 층 5가 결측이면 층 6(30.21 m)에서 재구성한다. 층 6은 수온약층 아래라
  직선으로 이으면 19 m를 차갑게 지나가므로, 온도가 아니라 **형태비**를 학습해 보정한다.
- **모델** — 층별 독립 LightGBM 회귀 3개.

### P3 — 유의파고 단기 예측

기준 시각으로부터 +3/6/9/12/18/24시간 유의파고를 예측한다.

| 리드 | +3h | +6h | +9h | +12h | +18h | +24h |
|---|---:|---:|---:|---:|---:|---:|
| RMSE (m) | 0.422 | 0.541 | 0.716 | 0.839 | 0.848 | 0.910 |
| 지속성 (m) | 0.599 | 0.615 | 0.846 | 0.869 | 0.937 | 1.071 |

- **베이스라인** — 지속성(기준 시각 파고 유지).
- **모델** — 리드타임별 독립 LightGBM 6개가 지속성 대비 잔차를 예측.
- **바람-파랑 비율** — 풍속² 대비 파고 등, 파랑 성장의 물리를 반영하는 몫을 명시적으로 넣는다.

## 4. 재현

### 환경

```
Python 3.11 이상 (3.14에서 검증)
lightgbm 4.6.0
scikit-learn 1.9.0
pandas, numpy, pyarrow
```

```bash
pip install -r requirements.txt
```

**외부 데이터와 사전학습 가중치를 일절 사용하지 않는다.** 세 파이프라인 전부 배포된
데이터만으로 처음부터 학습하며, 전체 재현에 약 7분이 걸린다(대회 제한 6시간).

### 데이터 배치

대회 데이터는 재배포가 금지되어 포함하지 않았다. 아래 경로에 두고 실행한다.

```
P1_qc_anomaly/       train.csv, test.csv, sample_submission.csv
P2_profile_restore/  observations.csv, test_index.csv, sample_submission.csv
P3_wave_forecast/    train_wave.csv, train_atmos.csv, test_context.parquet,
                     test_index.csv, sample_submission.csv
```

### 실행

```bash
./run_all.sh
```

세 제출물을 다시 만든 뒤 `artifacts/candidate_registry.json`의 SHA256과 대조하고,
하나라도 어긋나면 실패로 종료한다.

개별 실행:

```bash
python3 examples/baseline_submission.py        # P1, 약 6분
python3 examples/reconstruction_submission.py  # P2, 약 30초
python3 examples/wave_forecast_submission.py   # P3, 약 30초
```

### 데이터 없이 확인할 수 있는 것

대회 데이터는 배포할 수 없으므로 대부분의 방문자는 학습을 돌릴 수 없다. 그래도 다음은
그대로 열어볼 수 있다.

```bash
# 제출 답안이 등록된 해시와 맞는지
shasum -a 256 submissions/*.csv

# 학습된 모델을 텍스트로 열기 — 트리 구조와 피처 이름이 그대로 들어 있다
head -20 weights/p1/preset_standard/booster_0.txt

# 결정 임계값과 앙상블 결합 방식
cat weights/p1/ensemble.json

# 후보 선정 근거 (점수, 검증 구간, 이전 후보를 왜 버렸는지)
cat artifacts/candidate_registry.json
```

P1의 결정 임계값 `0.0248`은 검증 분할의 F1 최대점이 아니라 §2.3의 출력률에서 나온 값이다.
제출 파일의 양성은 169,011행 중 6,118행으로 정확히 3.62%다.

```

cosmos_os/
  competitions/ocean/

    reconstruction/         P2 (adapter, features, validation, submission, schema)
    forecasting/            P3 (adapter, cases, features, validation, submission, schema)
  modalities/anomaly.py     이상 탐지 피처 플러그인
  training.py               LightGBM 학습 래퍼
  tabular.py                결측 처리·피처 행렬 구성
  experiment/               실행 기록

submissions/                제출한 예측 답안 3종
artifacts/                  후보 레지스트리 (재현 대조용 해시)
run_all.sh                  세 제출물 재현 + 해시 검증
```

### 학습된 가중치

```
weights/p1/preset_standard, preset_full      P1 앙상블 2개 (확률 균등 평균)
weights/p2/layer_2, layer_3, layer_4         P2 층별 3개
weights/p3/lead_3h … lead_24h                P3 리드타임별 6개
```

LightGBM 부스터는 텍스트 형식이라 재학습 없이 열어볼 수 있다. 각 폴더의 `manifest.json`이
파일별 SHA256을, `ensemble.json`이 결합 방식과 결정 임계값을 기록한다.

## 6. 알려진 한계

- **P1의 로컬-리더보드 격차** (0.8238 → 0.7216). 모든 로컬 분할이 2024~2025년 안에 있고
  채점은 2026년이다. **어떤 로컬 검증도 연도 전이를 측정할 수 없다.**
- **drift·offset의 유효 표본은 행 수가 아니라 독립 이벤트 수**다. 학습 데이터 전체에
  drift는 32개, offset은 33개 구간뿐이다. 피처를 더해도 개선되지 않는 근본 원인이다.
- **P2·P3의 검증 표본이 작다.** P2는 26,061행 단일 창, P3는 54케이스다. P3는 3-fold 롤링
  백테스트를 병행해 보완했으나 소표본 변동은 남아 있다.
- **G-ORS 정점의 이상률이 창마다 5배 이상 변동**한다(반기별 0.010% / 7.374% / 0.000%).
  정점별 출력 배분을 조정하면 어느 창에서 측정하느냐에 따라 부호가 뒤집힌다.

## 7. 데이터 및 가중치

- 대회 데이터(`P1_qc_anomaly/`, `P2_profile_restore/`, `P3_wave_forecast/`)는 재배포가
  금지되어 포함하지 않았다.
- `submissions/`의 예측 답안은 우리 모델의 출력이며, 리더보드에 업로드한 답안과 동일하다.
- 사전학습 가중치를 사용하는 모듈은 포함하지 않았다. `weights/`의 부스터 11개는 전부
  배포된 데이터로 학습한 것이다.
